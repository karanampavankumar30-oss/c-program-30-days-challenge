 Algorithm – 

1. Start the program and create 40 seats using a 2D array.
2. Set all seats as available.
3. Display the menu and ask the user to choose an option.
4. Display the seats, book a seat or cancel a booking based on the user's choice.
5. For group booking, find empty seats together in the same row and book them.
6. Show the total booked seats, available seats and occupancy percentage.
7. Repeat the menu until the user selects Exit.
8. Stop the program.
