# c-program-30-days-challenge
Challenge 01 - Marks Calculator

A C program that takes marks for 5 subjects and calculates the total, 
average, and percentage.

Problem
Read marks for 5 subjects, then calculate and display the total, average, 
and percentage.

Algorithm
1. Start
2. Read the 5 marks
3. total = sum of all marks
4. average = total / 5
5. percentage = (total / 500) * 100
6. Print total, average, percentage
7. Stop

C Concepts Used
Variables, scanf/printf, arithmetic operators

Test Cases

Input: 80, 75, 90, 85, 70 -> Expected: 400 / 80 / 80% -> Got: 400.00 / 80.00 / 80.00%
Input: 65, 72, 68, 75, 80 -> Expected: 360 / 72 / 72% -> Got: 360.00 / 72.00 / 72.00%
Input: 95, 88, 92, 90, 85 -> Expected: 450 / 90 / 90% -> Got: 450.00 / 90.00 / 90.00%
