# c-program-30-days-challenge
Challenge 01 - Marks Calculator



Problem
Read marks for 5 subjects, then calculate and display the total marks, percentage and average 

Algorithm
1. Start
2. Read the 5 subject marks
3. total marks = sum of all marks
4. average = total  marks / 5 subjects
5. percentage = (total marks/ 500) * 100
6. Print total marks, average, percentage
7. Stop
