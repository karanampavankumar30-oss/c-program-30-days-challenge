
statement:Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive amount, classify it 
using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic operators, and variables. Do not use 
arrays, functions, or strings
algorithm:
1.Start.
2.Initialize all expense totals and counters to zero.
3.Enter an expense amount.
4.If the expense is 0, stop entering expenses. If it is negative, display “Invalid expense”.
5.If the expense is positive, add it to the total and count it.
6.Categorize the expense as Small (below 100), Medium (100 to below 500), or Large (500 and above). Update the corresponding count and total.
7.Repeat Steps 3–6 until the user enters 0.
8.Display the total expenses, category counts, category totals, and average expense.
9.Stop.
