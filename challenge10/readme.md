Algorithm :
1. Start the program.
2. Create arrays to store temperature, humidity and AQI values for 5 zones and 7 days.
3. Display the menu and ask the user to choose an option.
4. If the user chooses input data, enter the temperature, humidity and AQI values for each zone and day. Check that the values are valid.
5. If the user chooses display data, show all the entered values in matrix form.
6. If the user chooses averages, calculate the average temperature, humidity and AQI for each zone.
7. If the user chooses risk days, find the days when temperature, humidity or AQI crosses the given limits.
8. If the user chooses Green Index, calculate the index for each zone and arrange the zones according to their rankings.
9. If the user chooses recommendations, display suggestions to improve the environmental conditions in each zone.
10. If the user chooses Exit, display a thank-you message.
11. Repeat the menu until the user chooses Exit.
12. Stop the program.
