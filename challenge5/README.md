STATEMENT : Create a menu-driven C program that lets a user choose a mathematical operation. After each operation, display the menu again. The program must stop only when the user selects Exit
ALGORITHM : 
1. Start .
2. Display the menu and read the user's choice.

6. Repeat the menu until the user selects Exit.
