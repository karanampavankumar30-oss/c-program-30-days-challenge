Algorithm

1. Start the program and create a 2D array to store the grid values.
2.Ask the user to enter the grid size and check whether it is between 3 and 6.
3.Get all the grid values from the user and check whether they are valid.
4.Ask for the warning limit and check whether it is within the allowed range.
5.Display the grid entered by the user.
6.Find the total of each row and column and identify their highest totals.
7.Find the biggest value in the grid and display its position.
8.Count how many values reach or cross the warning limit.
9.Add the values in both diagonals and check whether their totals are equal.
10.Find the total of all the boundary values.
11.Check the middle values to find whether any value is greater than its four nearby values. If so, mark it as a hotspot.
12.Finally, display the result as Critical, Warning, or Normal based on the values found.
13.Stop .
